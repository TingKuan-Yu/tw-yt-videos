
## 建立 Git Commit

將目前所有變更建立為一個 Git commit，並使用簡潔、準確的英文 commit message。

## 建立 Git Commit 並 Push

將目前所有變更建立為一個 Git commit，使用簡潔、準確的英文 commit message，然後 push 至目前分支。

## 建立並推送 Git Commit

檢查目前的 Git 變更，確認不含憑證、暫存檔或無關內容後，將所有預期變更建立為一個 commit，並使用簡潔、準確的英文 commit message。

將目前分支推送至其 upstream remote；若尚未設定 upstream，使用 `origin` 建立追蹤關係。不得 force push。完成後回報 commit、分支、remote 及 working tree 狀態。

## 整理選取的 Prompts

請直接編輯目前的 Markdown 檔案，精簡並修正選取的 prompts，使內容精確、簡潔且易於使用；必要時新增或調整標題。


## 整理選取的 Prompts

請直接編輯目前的 Markdown 檔案，精簡並修正選取的提示詞，使內容精確、簡潔且易於使用；必要時新增或調整標題。

若包含輸入或輸出要求，請以「輸入」與「輸出」分類，將各項內容或路徑分行列於子清單；未指定的項目不需補寫。

格式範例：

- 輸入：
  - `Youtube-English-Teacher\Ariannita la Gringa\raw\I went to the MOVIES to teach English.md`
