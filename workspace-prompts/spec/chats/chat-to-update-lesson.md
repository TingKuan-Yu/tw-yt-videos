# 規格更新後的課程更新提示詞

將 `[課程檔名]` 替換為實際檔名（不含 `.md`），再複製所需提示詞執行。
每次只更新一份既有課程，以執行當下的完整規格為準；以下要求不取代規格。
執行提示詞即授權更新其中列出的目標；既有變更與更新要求衝突時，先確認，不逕行覆寫。

## 1. 僅更新課程

適用於 converted 仍符合來源轉換規格，只需依最新課程規格更新既有課程。

```markdown
請依最新課程生成規格，以 `update` 模式更新下列既有英文課程，不重新轉換來源。

- 適用規格：`workspace-prompts/spec/generate-english-lesson-prompts.md`。
- 唯讀內容來源：`house/converted/[課程檔名].md`。
- 既有課程與輸出：`house/lesson/[課程檔名]/`。
- 允許修改：上述課程目錄內規格定義的八個檔案、規格要求的舊檔遷移，以及
  `house/lesson/index.html` 中本課所需的入口與連結。

要求：
1. 完整讀取最新規格、指定 converted 與同名既有課程，記錄工作樹狀態及 converted SHA-256。
   本次授權更新上述範圍；保留符合規格的正確人工內容、有效導覽及來源限制。
2. 只以指定 converted 為事實來源，不讀取 source 或其他教材正文，不回寫 converted。
   若檔案缺失、配對不完整或格式無法可靠辨識，明確回報並停止，不自行補做轉換。
   若課程目錄不存在，停止並請使用者確認是否改用 `create`，不自動切換模式。
3. 比對既有課程與最新完整規格，修正所有適用差異，不只套用最近一次變更。
   從同一 canonical 資料同步更新課程 Markdown 與七份 HTML，保留規定的章節、
   頁面職責、HTML、TTS 及索引契約；不建立額外課程頁。
4. Reader 的 Markdown、主要 HTML 與 `bilingual.html` 均先中文後英文；
   `bilingual.html` 的 DOM、顯示與中英皆讀順序均為 `zh-TW → en-US`。
   沿用 converted 的配對與正文順序，不重新翻譯；其他頁依各自規格處理。
5. 依規格完成靜態、跨檔一致性、瀏覽器、TTS、響應式、連結及來源雜湊驗證。
   索引只為實際存在且驗證通過的頁面新增入口，保留其他課程與有效索引內容。
6. 檢查限定 diff、`git diff --check` 與最終工作樹狀態，確認 converted 未變、
   無範圍外修改；清除本次暫存檔，不回復既有變更。

回報輸入、修改檔案、規格差異與修正摘要、索引變更、驗證結果及待確認問題。
無法執行的檢查列為未驗證並說明原因，不以模擬語音冒充實際語音驗證，不宣稱全部通過。
不修改原始來源或無關課程，不上傳正文至外部服務，不得 stage、commit 或 push。
```

## 2. 重新轉換來源後更新課程

適用於來源轉換規格也有變更，須先更新 converted，再更新既有課程。

```markdown
請依最新兩份規格，先重新轉換指定來源，驗證通過後再以 `update` 模式更新既有英文課程。
本次授權更新指定 converted、同名課程及必要索引，不授權修改原始來源。

第一階段：來源轉換
- 適用規格：`workspace-prompts/spec/source-conversion.md`。
- 唯讀輸入：`house/source/[課程檔名].md`。
- 輸出與允許修改範圍：`house/converted/[課程檔名].md`；同名輸出存在時授權覆寫。
- 完整讀取來源並記錄工作樹狀態及 source SHA-256，依最新規格重新整理全文，
  每句繁中後緊接對應英文，保留原意、順序、來源資訊及不確定標記。
- 完成全文覆蓋、雙語配對、UTF-8、Markdown 硬換行及 source SHA-256 未變的驗證，
  並記錄通過驗證的 converted SHA-256；未通過時停止，不開始課程更新。

第二階段：課程更新
- 適用規格：`workspace-prompts/spec/generate-english-lesson-prompts.md`。
- 唯讀內容來源：第一階段通過驗證的 `house/converted/[課程檔名].md`。
- 既有課程與輸出：`house/lesson/[課程檔名]/`。
- 允許修改：上述課程目錄內規格定義的八個檔案、規格要求的舊檔遷移，以及
  `house/lesson/index.html` 中本課所需的入口與連結。
- 若課程目錄不存在，停止並請使用者確認是否改用 `create`，不自動切換模式。
- 比對既有課程與最新完整規格，修正所有適用差異，保留符合規格的正確人工內容與導覽，
  由同一 canonical 資料同步更新一份課程 Markdown 與七份 HTML。
- 本階段不重新讀取 source、不回寫 converted、不重新翻譯正文配對。
  Reader 的 Markdown、主要 HTML 與 `bilingual.html` 均先中文後英文；
  `bilingual.html` 的 DOM、顯示與中英皆讀順序均為 `zh-TW → en-US`。
- 完整遵守章節、頁面職責、HTML、TTS、索引及驗證契約，完成靜態、跨檔一致性、
  瀏覽器、TTS、響應式與連結驗證，確認 converted SHA-256 自第二階段開始至完成均未變。
  索引只為實際存在且驗證通過的頁面新增入口，保留其他課程與有效索引內容。

共同限制與回報：
- 兩階段不得交錯；任一步驟失敗時明確回報，停止依賴該結果的後續步驟。
- 既有變更與更新要求衝突時先確認，不逕行覆寫；不修改原始來源或無關課程。
- 完成後檢查限定 diff、`git diff --check` 與工作樹狀態，確認 source 未變且無範圍外修改，
  清除本次暫存檔，不回復既有變更。
- 分別回報兩階段的輸入、輸出、修正摘要、索引變更、驗證結果及待確認問題。
  無法執行的檢查列為未驗證並說明原因，不以模擬語音冒充實際語音驗證，不將部分完成稱為全部通過。
- 不上傳正文至外部服務，不得 stage、commit 或 push。
```
