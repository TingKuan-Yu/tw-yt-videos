# 來源轉換規格

將使用者指定的單一 Markdown 來源整理為易讀的繁體中文與英文對照文件，供後續英文課程使用。本階段只轉換來源，不生成課程。

## 輸入與輸出

- 輸入：`house\source` 下使用者指定的單一 `.md` 檔案。
- 輸出：`house\converted\[來源檔名].md`，沿用來源檔名。
- 來源檔案一律唯讀，不修改、改名、搬移或刪除。
- 未指定來源時，先請使用者提供精確路徑，不自動挑選或批次處理。
- 輸出目錄不存在時建立；同名輸出已存在時，先取得覆寫授權，不另加流水號或靜默覆寫。

例如：

```text
house\source\日本少子化房.md
→ house\converted\日本少子化房.md
```

## 轉換原則

1. 完整讀取指定來源，辨識標題、來源資訊、正文、補充內容及轉錄雜訊。
2. 無論原文是中文、英文或兩者混合，都輸出繁體中文與自然英文；中文使用台灣常用譯法。
3. 原文為中文時，整理中文並翻成英文；原文為英文時，保留有效英文並翻成中文。已有雙語對照時，核對配對並統一格式，不重複翻譯或重複列出正文。
4. 保留原意、正文順序、人物與講者歸屬、數字、單位、日期、否定、條件、語氣及不確定性。不得用摘要取代全文、補造資料或更新來源當時的說法。
5. 只移除可確認無意義的字幕序號、時間戳、匯出重複及無關宣傳；具有敘事或語氣功能的音效、重複及講者標記須保留。
6. 合併可確認屬於同一句的字幕硬換行，不跨講者或語意邊界。僅修正有明確上下文依據的拼字、標點及轉錄錯誤。
7. 無法確認的內容保守保留並標示 `[unclear]` 或 `[Needs verification]`，兩種語言都須呈現疑點。影響語意的修正或限制寫入「轉換註記」，不得猜測人名、數字或縮寫。
8. 翻譯與整理只寫入輸出檔。不得把翻譯冒充原語逐字引文，也不得上網補寫來源內容或上傳正文至外部服務。

## Markdown 格式

- 使用一個雙語 H1；既有章節標題也整理為中英雙語。
- H1 後列出 `source_path`、`original_language`（`zh`、`en` 或 `mixed`），以及來源實際提供的原始標題、網址、作者或日期。不補寫不存在的欄位。
- 以 `## 本文 / Main Text` 標示正文起點，正文內沿用原有章節與順序。
- 正文固定「一句繁體中文，緊接一句對應英文」，每組之間空一行；不將多句壓成一個摘要配對。
- 一組中的中文與英文各放一行，以 Markdown 硬換行分隔，使用行尾反斜線，不依賴檢視器保留普通換行。
- 清單保留層級，每項先中文後英文。表格保留欄列關係，可在文字儲存格中使用「中文 `<br>` 英文」。
- 程式碼、命令、公式及 URL 保留原樣，不改寫語法；有必要時在相鄰位置提供中英對照說明。
- 轉換註記放在正文之後，使用 `## 轉換註記 / Conversion Notes`；沒有疑點或需說明的修正時省略。

格式範例（示意文字，不得複製為實際來源內容）：

```markdown
# 原文標題 / English Title

- source_path: `house\source\原文標題.md`
- original_language: zh

## 本文 / Main Text

### 第一節 / Section One

這是第一句中文。\
This is the first sentence.

這是第二句中文。\
This is the second sentence.
```

## 執行與驗證

1. 確認來源為 `house\source` 內的指定一般檔案，輸出位於 `house\converted`，並檢查同名輸出及既有變更。
2. 以 UTF-8 完整讀取來源，記錄來源 SHA-256，依本規格建立雙語輸出。
3. 逐節比對來源與輸出，確認全文覆蓋、順序正確、無遺漏或重複，且每句中文後都有語意一致的英文。
4. 以 UTF-8 重讀輸出，檢查 Markdown 結構、硬換行、雙語配對、疑點標記及非預期亂碼。
5. 重算來源 SHA-256，確認未變；確認只新增或經授權更新指定輸出，未修改其他來源、課程、Git staging 或 commit。
6. 回報輸入、輸出、原文語言、轉換摘要、驗證結果及仍待確認的問題。檔案讀寫、翻譯或驗證失敗時明確回報，不宣稱完成。

## 交接英文課程

使用 `workspace-prompts\spec\generate-english-lesson-prompts.md` 處理本階段通過驗證的輸出，例如：

```text
輸入：house\converted\日本少子化房.md
輸出：house\lesson\日本少子化房\
```

後續課程只讀取指定的 converted 檔案，不回寫 converted，也不重新讀取或修改 source。原始語言與翻譯身分以輸出中的來源資訊為準。
